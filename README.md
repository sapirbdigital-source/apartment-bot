# בוט דירות — מבשרת ציון והסביבה

בוט שסורק קבוצות דיור בפייסבוק, מסנן מודעות שכירות רלוונטיות בעזרת AI, ושולח את מה שמתאים לוואטסאפ.

מבוסס על בוט הדירות של פלמחים, מותאם לחיפוש של ספיר: **אם חד-הורית עם שני ילדים (12 ו-8), אזור מבשרת ציון והיישובים סביב ירושלים, עד 4,000 ₪, עם רכב פרטי.**

---

## איך זה עובד

```
Apify (קבוצות פייסבוק)
   ↓  פוסטים גולמיים
סינון מקומי  ← זורק פוסטים קצרים וכאלה שכבר נשלחו (data/seen.json)
   ↓
Gemini 2.5 Flash  → (אם נופל) → Groq Llama 3.3
   ↓  JSON מובנה
אימות בקוד  ← בודק מחיר וחדרים במספרים, לא סומך על המודל
   ↓
Green API (וואטסאפ)  → נופל ל-CallMeBot → נופל לטלגרם
```

ערוצי השליחה ב-[notifier.py](notifier.py), הסדר נקבע ב-`config.NOTIFY_CHANNELS`.
ערוץ בלי סודות מוגדרים מדולג בשקט, כך שאפשר להפעיל רק את Green ולהתעלם משאר.

רץ ב-GitHub Actions פעם ביום בבוקר, וגם ידנית מכפתור.

## מה צריך להגדיר (פעם אחת)

### 1. Apify — הסורק של פייסבוק

זה החלק היחיד שלא נמצא בקוד. הטאסק יושב בחשבון Apify עצמו.

**אקטור:** `apify/facebook-groups-scraper` (הרשמי). הפלט שלו מכיל `text` ו-`url` —
בדיוק מה ש-`extract_text()` ו-`extract_url()` קוראים, אז אין צורך בשינוי קוד.

1. [Apify Console](https://console.apify.com/) → **Store** → `facebook-groups-scraper`
   של **apify**.
2. **⋮ → Create task**. חייב Task ולא Run — רק לו יש ID שה-API מקבל.
3. קלט:

   | שדה | ערך |
   |---|---|
   | `startUrls` | קישורי הקבוצות הציבוריות |
   | `resultsLimit` | `25` (ברירת המחדל 20) |
   | `viewOption` | `CHRONOLOGICAL` |
   | `onlyPostsNewerThan` | `1 days` |

4. ה-**Task ID** מה-URL → `APIFY_TASK_ID_1`.
   ה-**token** מ-Settings → API & Integrations → `APIFY_TOKEN_1`.

> ### ⚠️ קבוצות ציבוריות בלבד
> האקטור מצהיר במפורש שהוא עובד רק על קבוצות ציבוריות; סריקת קבוצות סגורות
> דורשת פרטי התחברות ומנוגדת לתנאי השימוש של פייסבוק. **חברות בקבוצה לא
> עוזרת** — הסורק לא משתמש בחשבון של ספיר בכלל.
>
> בדיקה מהירה: לפתוח את הקבוצה בגלישה בסתר. רואים פוסטים → ציבורית.
> את הבדיקה הזו חייבים לעשות **לפני** בניית ה-Task.

> ### על התקציב
> התוכנית החינמית: **$5 קרדיט לחודש**, לא מצטבר. האקטור הרשמי גובה
> **$0.005 לפוסט** ≈ 1,000 פוסטים בחודש.
>
> 6 קבוצות × ~8 פוסטים חדשים ביום ≈ 1,440 בחודש ≈ **$7.2** — קצת מעל.
> לכן `onlyPostsNewerThan: 1 days` והרצה **פעם ביום** (הרצה שנייה תשלם שוב
> על אותו חלון של 24 שעות).
>
> אלטרנטיבות זולות עם אותם שדות פלט:
> `memo23/facebook-public-group-posts-scraper` ($0.0015) ·
> `thedoor/facebook-group-post-scraper` ($0.00299).
> ההחלפה = עדכון `APIFY_TASK_ID_1` בלבד.
>
> בבוט המקורי (פלמחים) מיצוי הקרדיט היה בדיוק מה שהשתיק אותו. לכן הקוד תומך
> בשלושה חשבונות Apify ונופל מאחד לשני.

### 2. ערוץ ההתראות

הבוט רץ פעם ביום ושולח **דייג'סט אחד** עם כל הדירות שנמצאו
(`config.DIGEST`). לכן ערוץ "מיידי" לא קונה כלום כאן, ומייל — שהוא
הערוץ הכי פחות שביר — מתאים בול.

**מייל (ברירת מחדל).** `smtplib` הוא ספרייה סטנדרטית, אז אין תלות חדשה
ואין שירות צד-שלישי בדרך. ב-Gmail צריך **App Password** בן 16 תווים מ-
[myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
(דורש אימות דו-שלבי פעיל) — לא סיסמת החשבון. משתנים: `SMTP_USER`,
`SMTP_PASSWORD`, `EMAIL_TO`.

**ntfy.sh (פוש לנייד).** בלי חשבון ובלי מפתח: בוחרים שם נושא, נרשמים אליו
באפליקציה, והבוט עושה POST ל-`ntfy.sh/<topic>`. משתנה יחיד: `NTFY_TOPIC`.
> שם הנושא הוא הסוד היחיד שמגן על הערוץ — לבחור מחרוזת ארוכה ואקראית.

**וואטסאפ / טלגרם** נשארו בקוד כגיבויים:
- **Green API** — QR מ"מכשירים מקושרים". עובד, אבל זה סשן שמתנתק כשהטלפון
  לא מחובר לאורך זמן, וההתראות נפסקות בלי שגיאה.
- **CallMeBot** — שולחים `I allow callmebot to send me messages` ל-
  `+34 621 331 709` ומקבלים מפתח.
- **טלגרם** — [@BotFather](https://t.me/BotFather) → `/newbot`.

> הדרך הרשמית של Meta (WhatsApp Cloud API) דורשת חשבון עסקי מאומת ותבניות
> מאושרות מראש, כי הבוט יוזם את השיחה. לא שווה את זה לשימוש אישי.

הסדר נקבע ב-`config.NOTIFY_CHANNELS`; ערוץ בלי סודות מדולג בשקט, כך שאפשר
להגדיר רק את הראשון.

## בדיקה לפני הפעלה

בדוק שהסינון עובד כמו שצריך **בלי לשרוף קרדיטים של Apify**:

```powershell
pip install -r requirements.txt
$env:GEMINI_API_KEY = "AIza..."
python test_local.py
```

מריץ את הפרומפט על 9 מודעות דוגמה שמכסות את כל מקרי הקצה (מעל תקציב,
שותפים, סאבלט, "מחפשת דירה", למכירה, אזור לא רלוונטי) ומדפיס מה עבר ומה נדחה.
אם משהו לא מסתדר — לתקן ב-`config.py` ולהריץ שוב.

להרצה מלאה בלי לשלוח כלום:

```powershell
python bot.py --dry-run
```

## כוונון

הכל ב-[config.py](config.py). מה שהכי סביר שתרצה לשנות:

| הגדרה | ברירת מחדל | מתי לגעת |
|---|---|---|
| `BUDGET` | 4000 | אם התקציב משתנה |
| `BUDGET_STRETCH` | 4500 | התקרה שמעליה נחסם לגמרי |
| `CORE_AREAS` / `EXTENDED_AREAS` | מבשרת + סביבה | להרחיב/לצמצם אזור |
| `MIN_ROOMS` | 3 | אם 2.5 חדרים בסדר גמור |
| `COMMUTE_TARGET` | מרכז ירושלים | אם יש מקום עבודה ספציפי |
| `SEND_IF_NO_PRICE` | True | אם מודעות בלי מחיר מציפות |

תדירות ההרצה — ב-[.github/workflows/main.yml](.github/workflows/main.yml), שורת ה-`cron`.

## נקודות שכדאי להכיר

**מעט מדי תוצאות?** בשוק הזה 4,000 ₪ למשפחה עם 2 ילדים זה תקציב הדוק —
במבשרת עצמה דירת 3 חדרים היא בערך 5,500–7,000 ₪. אם הוואטסאפ שקט,
הבעיה כמעט תמיד היא אחת משתיים: או ש-Apify לא מחזיר פוסטים (בדוק את הלוג
ב-Actions), או שהתקציב באמת חוסם הכל. `BUDGET_STRETCH` הוא הכפתור לזה.

**כפילויות.** `data/seen.json` זוכר כל מודעה שנותחה, ל-45 יום.
הוא נשמר בחזרה ל-repo בסוף כל הרצה — מה שגם מונע מ-GitHub להשבית את
ה-schedule אוטומטית (זה מה שקרה לבוט המקורי אחרי 60 יום בלי פעילות).

**מודעה שהניתוח שלה נכשל** לא נכנסת ל-`seen.json` בכוונה, כדי שתנותח שוב
בהרצה הבאה במקום ללכת לאיבוד.

**מחירים.** המודל מתבקש להחזיר `price` כמספר, והבדיקה מול התקציב נעשית
ב-Python ולא ע"י המודל — מודלים לא אמינים בגבולות מספריים. אם אין מחיר
במודעה, `price=null` והמודעה נשלחת עם "מחיר לא צוין" (ניתן לשינוי).

**קצב.** `SLEEP_BETWEEN_CALLS = 5` שניות. אל תוריד — זה מה שמונע 429
מהמכסה החינמית של Gemini.

## פרטיות

הבוט קורא פוסטים פומביים בקבוצות שהחשבון חבר בהן, ושולח סיכום לצ'אט פרטי אחד.
הוא לא שומר מספרי טלפון, לא בונה מאגר, ולא יוצר קשר עם אף אחד אוטומטית —
יצירת קשר עם מפרסם היא פעולה ידנית של ספיר. אין לשנות את זה בלי לקרוא את
תנאי השימוש של פייסבוק ואת חוק הגנת הפרטיות.
